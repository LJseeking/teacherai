# 产品整体逻辑与页面职责

## 核心目标

智能体先处理大多数常见的线上学习问题，老师只接手需要个体判断或适合课堂统一讲解的问题，以减少重复答疑和备课负担。页面中的比例与案例目前为演示数据，不代表实际效果承诺。

## 页面分工

1. **我的智能体**：看本周处理概况、少量需要老师确认的知识、学生待办；进入试用、分享和设置。
2. **我的知识库**：日常课程材料汇入同一处。系统负责整理；老师只确认不确定、冲突或重要方法。确认后的知识才用于学生辅导。
3. **学生问题**：展示常规问题由智能体在线处理的总体情况；少数人工事项分为电话沟通和带入课堂讲解。页面内提供少量答疑抽查，老师标记符合或需调整。
4. **准备下一课**：将反复出现的学生卡点带入备课草稿，老师检查后用于课程。
5. **学生端**：在视频时间点、知识点、作业题目处提问；也可随时发起学习或个人求助。智能体依据老师确认的知识回答；必要时提醒联系老师或可信任的大人。

## 是否需要新增页面

目前不增加主导航页面。质量抽查已嵌入「学生问题」，首次设置收在智能体范围设置中。后续若真实业务需要机构管理员查看多位老师、班级和权限，再独立建设机构管理端；这不是教师个人智能体 MVP 的必需部分。

## 当前演示限制

页面状态存于本地浏览器；材料没有实际上传/解析； AI 没有真实模型调用；电话只记录本地计划；课程数据和答疑统计均为样例；小程序码是占位图。正式产品需后端、身份权限、模型与知识检索、通知和小程序接入。
