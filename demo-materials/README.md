# 知师产品演示材料包

本材料包用于演示老师知识库、学生课中提问、老师介入答疑和下一课备课流程。所有人物、课程和学生案例均为虚构示例。

## 建议演示顺序

1. 以 `01-教师档案.md` 介绍林老师。
2. 在老师端上传 `02-课程视频转写稿.txt`、`03-教学文章.md` 和 `04-课件提纲.md`。
3. 说明系统从材料提炼 `05-老师知识卡.md`，由老师核对后确认入库。
4. 用 `06-作业与典型错误.md` 展示学生在具体题目处提问。
5. 按 `07-学生提问与老师介入脚本.md` 演示 AI 陪练、转交老师和老师回复。
6. 用 `08-下一节课备课建议.md` 展示答疑数据如何反馈到课程设计。

## 说明

当前网页原型没有真实 AI 分析、云端材料上传、微信小程序或跨设备消息同步。材料上传功能目前只登记文件名称与状态。演示时应把知识卡和备课建议称为“基于样例材料整理的演示结果”，不要描述为系统已自动生成。
