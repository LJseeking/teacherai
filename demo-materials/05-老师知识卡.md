# 老师知识卡（演示整理稿）

## 知识卡 1：先用变化关系判断一次函数图像方向

- **适用问题**：学生需要判断一次函数图像方向，或只会背结论却解释不出原因。
- **老师的方法**：先观察 x 增加时 y 如何变化，再用变化关系解释图像方向。
- **教学步骤**：
  1. 读出函数表达式或图像上的两个点。
  2. 判断 x 增加时函数值变大还是变小。
  3. 让学生用“因为……所以……”表达理由。
  4. 再检查是否把截距和方向混淆。
- **典型例子**：y = 2x + 1 中，x 每增加 1，y 增加 2，所以图像从左下向右上。
- **常见误区**：只背“正/负”口诀；把常数项当作方向依据；只给答案不解释。
- **适用边界**：学生若还不理解变量和函数值，需要先补变量变化的基础概念。

## 知识卡 2：学生说“不知道从哪开始”时，先还原思考过程

- **适用问题**：学生表示听懂了但独立做题无法起步。
- **老师的方法**：先让学生说题目给了什么、要找什么、准备做的第一步，再定位卡点。
- **后续处理**：概念不清补概念；步骤不熟练过程；计算失误再练计算和检查。
- **注意**：不要仅凭答错就归因于粗心。
