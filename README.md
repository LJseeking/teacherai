# 知师：教师与学生双端产品演示

这是一个面向教育机构的教师知识库与学生学习辅导产品前端演示。

## 本地预览

直接在浏览器打开 `prototype.html`。

## 当前包含

- 教师工作台与教师知识库材料入口
- 学生课程学习、视频/作业上下文提问
- 学生随时求助入口与老师介入提示
- 教师答疑数据、介入队列和回复交互
- 下一节课程设计建议
- 微信小程序扫码入口占位

## 演示范围

本项目目前是单页前端演示。模拟统计、课程、学生案例和二维码均为演示数据/占位内容；材料记录保存在当前浏览器本地。尚未接入真实账号、云端存储、AI 模型、视频处理、微信小程序或跨设备消息同步。

## 产品主线

教师端以“我的智能体”为中心：设置服务对象和教学范围 → 导入材料并确认知识 → 试用回答 → 分享给学生 → 查看答疑并改进知识或备课。模型细节由系统默认处理，教师主要负责确认教学方法和人工介入边界。

当前网站为交互演示版；设置项、材料状态和答疑状态保存在本机浏览器，不会跨设备同步。
