# 知师：教师与学生双端产品演示

这是一个面向教育机构的教师知识库与学生学习辅导产品前端演示。

## 本地预览

直接在浏览器打开 `prototype.html`。

## 当前包含

- 教师工作台与教师知识库材料入口
- 学生课程学习、视频/作业上下文提问
- 学生随时求助入口与老师介入提示
- 教师答疑数据、介入队列和回复交互
- 下一节课程设计建议
- 微信小程序扫码入口占位

## 演示范围

本项目目前是单页前端演示。模拟统计、课程、学生案例和二维码均为演示数据/占位内容；材料记录保存在当前浏览器本地。尚未接入真实账号、云端存储、AI 模型、视频处理、微信小程序或跨设备消息同步。
